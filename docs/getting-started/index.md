# شروع کار

این بخش مسیر راه‌اندازی مستندات را از نصب ابزار تا افزودن صفحه جدید پوشش می‌دهد.

## چه چیزی در این ریپو هست؟

| بخش | نقش |
|---|---|
| `docs/` | منبع Markdown |
| `mkdocs.yml` | تنظیم قالب، زبان و افزونه‌ها |
| `.github/workflows/pages.yml` | بیلد و انتشار روی GitHub Pages |

بعد از هر push روی شاخه `main`، GitHub Actions سایت را می‌سازد و روی Pages منتشر می‌کند.
