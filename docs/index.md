# مستندات سازمان

به سایت مستندات خوش آمدید. فایل‌های Markdown داخل پوشه `docs/` با قالب یکسان به HTML تبدیل می‌شوند و منوی سایت از همان ساختار پوشه‌ها ساخته می‌شود.

از منوی کناری می‌توانید بخش‌های مختلف را ببینید.
