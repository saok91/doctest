# پایش

وضعیت انتشار را از تب **Actions** در GitHub ببینید. اگر بیلد شکست بخورد، سایت قبلی روی Pages باقی می‌ماند تا اجرای بعدی موفق شود.

## بررسی سریع

- لینک شکسته باعث شکست `--strict` می‌شود.
- خطای سینتکس Mermaid ممکن است بیلد را رد کند ولی نمودار را در مرورگر خالی بگذارد؛ نمودار را در `mkdocs serve` هم ببینید.
