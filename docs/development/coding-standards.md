# استانداردهای کدنویسی

این صفحه یک نمونه برای مستندات تیمی است. قواعد واقعی سازمان را اینجا جایگزین کنید.

## اصول کلی

- نام فایل‌های مستندات کوتاه و انگلیسی باشد.
- عنوان داخل فایل فارسی و واضح باشد.
- برای هشدار و نکته از admonition استفاده کنید.
